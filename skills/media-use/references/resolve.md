# 平台素材接入

先遵循 [平台约定](platform.md).  此文件保留原版入口名, 不再调用 resolve 的供应商级联.

1. 检查当前任务已提供的素材和实际需求, 选择已有合适素材或对应平台生成工具.  不扫描其他用户或其他任务的全局缓存.
2. 通过对话中的真实工具 schema 调用, 根据实际状态机制等待终态.  不从 shell 调用工具名, 不猜 API, 不把 pending 或 taskId 当完成.
3. 成功后读取结果明确提供的 localPath, 类型和文件信息.  核验本地文件可读, 非空且类型符合, 再复制到项目 assets/images/, assets/videos/ 或 assets/audio/.  不猜下载 URL 对应的本地路径.
4. 图片核对尺寸, 音视频用 ffprobe 核对流类型, 时长和实际可解码内容.  需要格式变化时真实转码, 不仅改扩展名.
5. 将实际相对路径写进 HTML, 例如 assets/audio/scene-01.mp3.  普通素材清单可记录用途, 文件, 工具和实测时长, 不假造 HeyGen provenance 或供应商 ledger.
6. 检查 snapshot 里的素材加载和最终成片.  失败时保留日志和已完成文件, 记录工具或 CLI 的具体 error/detail, 不输出凭据或带授权参数的 URL.

平台结果没有可读 localPath 时, 报告素材接入失败.  按当前工具明确提供的文件接入机制处理, 不自行拼接口或要求供应商 key.  平台生成的素材与最终交付是不同步骤, 遵循 platform.md 的交付约定.
